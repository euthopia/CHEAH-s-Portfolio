# CHEAH CHERN EU · 3D Portfolio

Interactive 3D portfolio of **CHEAH CHERN EU**, AI Cloud Solution Architect at Huawei Malaysia.
World engine based on [Bruno Simon's folio-2025](https://github.com/brunosimon/folio-2025) (MIT).

## What's custom

- `sources/data/profile.js`: personal info (single source of truth)
- `sources/data/projects.js`, `lab.js`, `social.js`: areas content
- `sources/Game/Extras/`: **CHEAH-GPT** (in-world assistant, press `C`), **Neural Sky** (living neural network above the landing zone), animated report card
- `scripts/generate-identity.py`: regenerates career stones, project/lab cards, time-machine screens and share image (`python3 scripts/generate-identity.py`)
- `static/cv.html`: quick 2D profile for recruiters
- `.github/workflows/deploy.yml`: builds and deploys to GitHub Pages
- `.github/workflows/deploy-cloudflare.yml`: builds and deploys to Cloudflare Pages (`cheah-chern-eu.pages.dev`); needs the `CLOUDFLARE_API_TOKEN` repository secret
- `npm run deploy:cloudflare`: manual deploy with Wrangler (needs `CLOUDFLARE_API_TOKEN` and `CLOUDFLARE_ACCOUNT_ID`)

## Setup

Create `.env` file based on `.env.example`

Download and install [Node.js](https://nodejs.org/en/download/) then run this followed commands:

``` bash
# Install dependencies
npm install --force

# Serve at localhost:1234
npm run dev

# Build for production in the dist/ directory
npm run build
```

## Blender

### Export

- Mute the palette texture node (loaded and set in Three.js `Material` directly)
- Use corresponding export presets
- Don't use compression (will be done later)

### Compress

Run `npm run compress`

Will do the following

#### GLB

- Traverses the `static/` folder looking for glb files (ignoring already compressed files)
- Compresses embeded texture with `etc1s --quality 255` (lossy, GPU friendly)
- Generates new files to preserve originals

#### Texture files

- Traverses the `static/` folder looking for `png|jpg` files (ignoring non-model related folders)
- Compresses with default preset to `--encode etc1s --qlevel 255` (lossy, GPU friendly) or specific preset according to path
- Generates new files to preserve originals

#### UI files

- Traverses the `static/ui.` folder looking for `png|jpg` files
- Compresses to WebP
